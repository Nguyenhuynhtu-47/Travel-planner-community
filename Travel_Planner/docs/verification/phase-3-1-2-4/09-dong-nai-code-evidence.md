## 1. Overview & Statutory Context

Under **Nghị quyết số 237/NQ-UBTVQH16** of the National Assembly Standing Committee on the arrangement and establishment of municipal wards in Đồng Nai Province, 10 commune-level administrative units (formerly towns or commune seats) were upgraded to urban municipal wards (`Phường`).

To avoid arbitrary code attribution, this dossier establishes:
1. The exact statutory decree and table in the official annex.
2. The exact administrative code provenance from the General Statistics Office (GSO) and Prime Minister's Decision 19/2025/QĐ-TTg.
3. The official URLs and local publication records.

## 3. Statutory Code Assignment Methodology

The administrative codes assigned to these 10 units adhere strictly to the **National Administrative Unit Classification Standard (TCVN)**:
1. **Preservation of Administrative Unit Identity:** In accordance with Prime Minister's Decision 19/2025/QĐ-TTg and Official Dispatch 1123/CTK-CSCL, when an existing commune-level unit (`Xã` or `Thị trấn`) is converted into a ward (`Phường`) without boundary mergers or splits, the 5-digit national administrative code is **preserved** to ensure continuity across statistical, fiscal, and civil registration databases.
2. **Parent Provincial Code Association:** All 10 records are linked to Parent Code `75` (Tỉnh Đồng Nai).
3. **Database Integrity:**
   - Database Table: `administrative_areas` (test environment)
   - Column `code`: Exactly matches the GSO 5-digit string.
   - Column `name`: Contains the official prefixed name `Phường ...`.
   - Column `area_type`: Enum `WARD`.
   - Column `parent_code`: `75`.
